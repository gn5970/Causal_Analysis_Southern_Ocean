# Causal_Analysis_Southern_Ocean
Analysis of main drivers of Chl increase in the Southern Ocean


The code examine causality in what drives Chl-a increase in the Southern Ocean. The PCMCI files runs the causal analysis for drivers of Chl-a and for drivers of MLD anomalies.

The data used which in the code are named 
Salt_bsoseI155_2013to2023_monthly.nc
BioMass_bsoseI155_2013to2023_monthly.nc
NPP_bsoseI155_2013to2023_monthly.h5
MLD_bsoseI156_2013to2024_monthly.nc
SIArea_bsoseI155_2013to2023_monthly.h5
oceTAUX_bsoseI155_2013to2023_monthly.h5
oceTAUY_bsoseI155_2013to2023_monthly.h5
DFrIFE_bsoseI155_2013to2024_monthly.nc
ADVrFE_bsoseI155_2013to2024_monthly.nc
Strat_bsoseI155_2013to2023_monthly.nc
Chl_bsoseI155_2013to2023_monthly.h5
Llim_bsoseI156_2013to2024_monthly.nc
